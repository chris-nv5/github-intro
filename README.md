# GitHub Learning Group

A beginner-friendly repository for learning Git and GitHub together as a coworker group.

## Goals
- Learn Git fundamentals
- Practice branching and pull requests
- Understand GitHub collaboration workflows
- Build confidence using GitHub in a team environment

## Suggested Learning Path
1. Git basics
2. Branching and merging
3. Pull requests and code review
4. Issues and project tracking
5. GitHub workflow best practices

## Topics Covered
- Git installation and setup
- Creating repositories
- Cloning and committing
- Creating branches
- Merging and resolving conflicts
- Using pull requests
- Working with issues
- Basic team collaboration flow

## Folder Structure
- `exercises/` – hands-on practice files
- `resources/` – cheat sheets and references
- `notes/` – personal or team learning notes
- `templates/` – issue and PR templates

## Beginner Plan
### Week 1
- Install Git and GitHub account setup
- Create a repo
- Make your first commit

### Week 2
- Learn branching
- Commit and switch between branches

### Week 3
- Practice pull requests
- Review and merge changes

### Week 4
- Explore issues and project tracking
- Learn collaboration workflows

## Recommended Tools
- Git
- GitHub
- VS Code
- Terminal or command prompt

## Practice Activities
- Create a small repo and commit a file
- Create a feature branch
- Open a pull request
- Leave feedback on a teammate’s change
- Resolve a merge conflict
